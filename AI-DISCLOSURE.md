# AI development disclosure

This project was created with substantial assistance from **OpenAI Codex**, an AI coding agent, under the direction of Chris Seabrooke / Seabrooke.Astronomy.

Codex generated and revised the HTML, CSS, JavaScript, chart rendering, CSV processing, diagnostics, heuristic variability screening, export functions, themes, synthetic dataset generator, tests, and documentation. Chris provided the requirements, real Seestar files for testing, design feedback, and feature requests. The initial GitHub publication was also prepared and performed with Codex assistance.

The synthetic eclipse dataset is generated by an AI-authored deterministic simulation. It is not an observation, catalog source, physical binary-star fit, or scientific discovery.

## Validation and limits

Automated tests exercised the actual application functions against owner-supplied Seestar files against their specified private reference assertions. Additional tests used synthetic data and a simulated browser DOM/canvas. See [photometry/VALIDATION.md](photometry/VALIDATION.md) for the checks performed and their limits, and [tests/README.md](tests/README.md) for reproducible public checks.

Those tests are not independent scientific review or a complete accessibility/security audit. The initial local-file visual browser check was blocked by the browser automation tool's protocol policy. Heuristic variability screening is not a statistical significance estimate, event classification, or recurrence forecast. A tracking flag does not establish a telescope slew or invalidate an observation.

Later, the HTTPS deployment was checked in a live browser for successful synthetic-data import, chart display, screening summary, and navigation among the collection, project, and analyzer. This was targeted verification, not complete cross-browser, gesture, export-dialog, print, or accessibility coverage. The documentation audit also preserved executable runtime tokens and reran public and owner-supplied real-data regressions; see the changelog.

Users and contributors should review the code, verify important results independently, and document changes to the methods. AI assistance does not imply endorsement or certification by OpenAI, ZWO, or any astronomical institution.

The session audit, provisional coordinate associations, gallery/review ranking, ASTAP catalogue reader, explicit SIMBAD links and remembered-folder logic were also developed with Codex assistance under the owner's direction. See the current validation/handoff record for algorithm limits and user-observed Chrome behavior. Catalogue proximity and gallery rank are not scientific identification or detection confidence.
