Your original files stay read-only on your device. Analysis needs no account, installation, paid software or cloud processing. Optional ASTAP lookup reads your local database; SIMBAD receives coordinates only when you click its link.

What you can do

Find observations worth a closer look

Import a collection, in either order

Read a completed MyWorks folder, a field folder, or dedicated Photometry target CSVs. Add more observations without rescanning everything. Read files in place on an accessible device, or copy them locally if convenient. Originals stay untouched.

Choose an object and its observing runs

Explore one provisional object across imported sources. Select all runs, one run or a custom selection. Time gaps and field changes suggest breaks; original brightness offsets remain visible rather than being silently corrected.

View all your miniature curves

Compare the filtered collection as a gallery in four tile sizes, sorted by review priority, coverage or range. Open a full curve, return to its highlighted tile, or let the gallery close automatically. Every major section can collapse.

See measurement quality before filtering

SNR and uncertainty histograms show how measurements are distributed. Move data-range sliders or enter exact cutoffs. Striped bars show what would be flagged; the reason breakdown explains overlapping flags. Colours follow all five themes.

Inspect overlaps and reference roles

Exact observation identities avoid double-counting target/field exports. Inspect duplicate conflicts, source coverage and Seestar-reported reference-star roles. Reference-only gallery browsing helps inspect comparison measurements; it does not verify their constancy.

Make a shortlist for further analysis

Mark objects beside a gallery tile, the object selector or the main chart. Add shared review notes and export the current object’s individual observations for VStar, with optional quality filtering. Download shortlist notes and source provenance separately.

Optional identification and setup

One Setup section holds ASTAP database selection, remembered folder access and VStar guidance. ASTAP software is not required to read supported local catalogue cells. SIMBAD opens only when clicked; nearby catalogue objects are candidates, not confirmed identities.

Keep a useful record

Save a chart PNG, binned CSV, offline HTML report, provisional catalogue snapshot or review notes. Observation values stay in browser memory until exported; remembered folders do not save your analysis.

A simple observing workflow

Import, explore, inspect, follow up

  1. Import observations

    Choose a MyWorks/field folder or target CSVs. Use Add to collection for another folder or night. Collection analysis requires absolute exposure-start JD or MJD.

  2. Choose the object and runs

    Names are aliases; conservative coordinate matching makes provisional groups. Inspect source coverage and possible breaks before combining nights.

  3. Compare and inspect

    Browse miniature curves, open interesting shapes, and review uncertainty, SNR, time gaps and tracking. A high review rank is a prompt to look, not a detection.

  4. Shortlist and follow up

    Mark an object and add a note. Export its selected runs for VStar, or use source references to find the FITS exposures for independent measurement.

The local workflow has been tested in normal desktop Chrome. Full native cross-browser testing remains incomplete. Folder access is optional; individual CSV selection is available. Reopening a remembered folder can require renewed permission.

Triage before deeper analysis

A useful first look, with a clear next step

This free browser tool is for curious Seestar owners, clubs and educators. Its strength is letting you compare many curves visually, inspect data quality and carry a shortlist into deeper work. An interesting curve might be a real change, a tracking or measurement effect, or simply inconclusive.

For time-series analysis: export individual measurements to VStar, a free desktop tool for further plotting and period analysis. Ordinary and quality-filtered exports have been tested successfully in VStar 2.25.0 on macOS. Exporting does not calibrate the measurements or make an AAVSO submission.

For independent brightness measurements: take the original FITS exposures to a dedicated photometry tool such as AstroImageJ. Calibration, aperture/comparison-star choices and image quality need separate assessment. FITS headers provide metadata; remeasuring brightness requires the image pixels. This analyzer reads CSV measurements and does not perform FITS photometry.

Position matching can split or misassociate stars; IDs are local to the imported collection. Different nights can have uncorrected zero-point offsets. No complete eclipse detection, confirmed identification, discovery verdict or standard-passband calibration is promised. Read the workflow and limitations ↗

Try it before loading your observations

A fictional eclipse to explore

Download the synthetic eclipse CSV, open the analyzer, and import it in step 1. The included example contains 1,081 simulated measurements across six hours, including a midnight crossing. Inspect the dip, adjust the bins and try the chart/report exports. It is educational sample data, not a real observation.
