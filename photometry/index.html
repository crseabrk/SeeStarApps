Your data stays
with you.

Your original files stay read-only on your device. Analysis needs no account, installation, paid software or cloud processing. Optional ASTAP lookup reads your local database; SIMBAD receives coordinates only when you click its link.

What you can do

From one target to a field of curves

Target logs and session audits

Import one or several named-target CSVs, then scan the frame CSVs to check exact observation overlap, missing counterparts and differences. The audit avoids counting the same exported measurement twice.

Provisional field-star tracks

Scan without a target log to explore unnamed measurements. Coordinate-based associations receive fixed IDs within the scan. Search or filter by observation count, then plot a selected track.

A gallery of actual light curves

Browse miniature binned curves in four selectable tile sizes. Choose shared or individual scales and sort by review priority, observation count or binned range. Collapse from either end, optionally close it on selection, and reopen it above the main chart or return to the selected tile.

Measurement and tracking diagnostics

Inspect clock-aligned bins, uncertainty, SNR, sensor drift and possible movement events. Adjust quality filters, zoom and pan, and choose five themes. Exploratory variability shading highlights trends worth checking.

Optional offline catalogue lookup

Select an extracted ASTAP .1476 database folder or files, then explicitly look up the plotted position. No ASTAP application is needed. Results are nearby position/magnitude candidates; these compact records have no object names.

Find possible identifiers in SIMBAD

Open a coordinate search for the selected track or a local catalogue candidate in a new tab. Searches happen only when clicked. Inspect possible matches and copy an identifier; the app does not automatically identify or rename a track.

Exports with a trail back to the data

Save a high-resolution PNG, processed binned CSV or printable offline HTML report. Export the session audit for overlap/provenance and a star-catalogue snapshot for provisional IDs and positions.

Remember folders and keep your place

Reopen remembered session/database folders explicitly, or forget the selections. The numbered workflow, Back to gallery and Back to top controls guide navigation. Saved folder access does not save observations or analysis results.

Choose your starting point

One target—or general exploration

  1. Load a target log (optional)

    Import the dedicated CSV first and select its target. For a general field scan, skip this step. Importing or changing a log after scanning requires another scan for reconciliation.

  2. Scan the session folder

    Choose or reopen a completed session. The app reads CSVs and counts FITS/JPEG files without loading image data. Ordinary file selection is available when folder access is unsupported.

  3. Browse the gallery

    Filter tracks, adjust tile size and scales, and inspect shapes across the field. Click a curve to open the full chart; collapse the gallery whenever useful.

  4. Inspect, look up and share

    Review quality and tracking, request a catalogue lookup if useful, and export results. Return directly to the chosen tile or back to the page top.

Use normal desktop Chrome for the folder workflow demonstrated so far. Other browsers can use supported file-selection controls; full cross-browser testing remains incomplete. Browser permission renewal may be required when reopening remembered folders.

What the results mean

An accessible explorer, with clear limits

This is for curious Seestar owners, clubs and educators exploring variable-star observations without paid analysis software. It helps you assess existing measurements and choose observations worth investigating in dedicated measurement tools.

Field associations are experimental: one physical star can split into several tracks, some measurements remain unassigned, and mistakes are possible. IDs are local to a scan; exported catalogues are snapshots, not resumable sessions. Review priority is not an eclipse probability, catalogue proximity is not confirmed identity, and no result promises every eclipse, a discovery or calibrated scientific magnitudes.

Folder scans are cancellable and source files stay untouched. Large fields use browser memory and documented limits apply. FITS image remeasurement, cross-session identities and automatic catalogue/passband calibration are outside current capability. Read the full workflow, limits and verification notes ↗

Try it before loading your observations

A fictional eclipse to explore

Download the synthetic eclipse CSV, open the analyzer, and import it in step 1. The included example contains 1,081 simulated measurements across six hours, including a midnight crossing. Inspect the dip, adjust the bins and try the chart/report exports. It is educational sample data, not a real observation.
